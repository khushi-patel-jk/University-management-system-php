# University Management System PHP

A PHP and MySQL based University Management System developed as a college project.

## Project Description

The University Management System is a website developed using PHP, MySQL, HTML and CSS. It helps manage university courses and student registration through a simple and user-friendly interface.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Features

- Home page
- About/Contact information
- Course management
- Course details
- Student registration
- Admin panel
- Add and manage courses
- MySQL database connectivity
- Fetch data from database
- Delete course records

## Project Structure

admin/          - Admin panel files
images/         - Website images
index.php       - Home page
courses.php     - Courses page
registration.php - Student registration
contact.php     - Contact page
school.sql      - Database file
style.css       - Website styling
